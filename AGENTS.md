# Gramlyze: порядок роботи

- На початку коротко підсумуй завдання та його межі; працюй саме в Gramlyze.
- Реалізацію й HTTP/браузерні перевірки виконуй на `http://gramlyze.loc`; production-профіль перевіряй ізольованими локальними тестами.
- Після завершення завдання на зміни перевір результат, зроби commit і push пов’язаних перевірених змін у робочу гілку, якщо користувач явно не наказав інакше. Дотримуйся PR-only політики `main`.
- Деплой потребує окремого дозволу. Commit/push самі по собі не дозволяють деплой.
- Не коміть секрети, `.env`, runtime caches, дампи/backups, приватні діагностичні дані або сторонні незавершені зміни. Явно обирай файли/hunks і перевіряй staged diff.
