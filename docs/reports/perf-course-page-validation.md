# PERF‑19 — одна валідація пакета для сторінки уроку

База — PERF‑18, `8b264298457bae0d00cc9b3eee1cea401da764f8`. Apache `gramlyze.loc` обслуговує `D:/DEV/htdocs/gramlyze.loc/public`; Git HEAD цієї копії — `41820a2bebdf69004fa7209a2a38457f93efabbd` з локально застосованими попередніми оптимізаціями. Checkout не перемикали і не скидали.

Вхідні файли A на диску обслуговуваної копії та в робочій гілці збіглися побайтово: `TheoryNativeContentRelease.php` (SHA‑256 `ff60e6506c600a9b3d4978bf63056b066b5a4f11feb1e85a4a19f051b26a13d8`), `TheoryCourseController.php` і `TheoryCourseManifestService.php`. Перевірки виконувались тільки на українських маршрутах `http://gramlyze.loc/`, без мовних префіксів і без змін правил доступу.

Ділянка: `TheoryCourseController::lesson()/test()` → `TheoryCourseManifestService::resolvePageForLesson()` → обробники `preserveCoursePage()`. У A спільний `TheoryNativeContentRelease::preserveCoursePage()` після першого `load()` і `validate()` викликав `binding()` окремо для кожного очікуваного блока без підготовлених даних. Кожна така прив’язка могла повторно читати та повністю перевіряти той самий пакет.

Зміна в `app/Support/TheoryNativeContentRelease.php`: цикл передає в `binding()` уже перевірені `[$patch, $master]` з цього виклику. Умови прив’язки сторінки та кожного блока, порядок і перевірка subtitle, повернення оригіналу на будь-якій невідповідності й відновлення через копії залишилися без змін. Кожен новий виклик перевіряє джерела знову. `presentation()` і поведінку PERF‑18 для `preserveExcludedTextBlock()` не змінено. Кешу не додано.

Маршрути, знайдені у фактичному маніфесті [курсу](http://gramlyze.loc/courses/english-grammar-theory):

- [Parts of Speech](http://gramlyze.loc/courses/english-grammar-theory/lesson/basic-grammar/parts-of-speech), власник M83, сторінка 22.
- [One / Ones](http://gramlyze.loc/courses/english-grammar-theory/lesson/zaimennyky-ta-vkazivni-slova/one-ones), власник M77, сторінка 123.
- [Тест Parts of Speech](http://gramlyze.loc/courses/english-grammar-theory/lesson/basic-grammar/parts-of-speech/test), власник M83.

Ця оптимізація підтверджена для гілки відновлення сторінки курсу, а не для загальних маршрутів `/theory/…`. Реальні дані й доступ до маршрутів перевіряли окремо від ізольованих fixtures.

## Тести

`tests/Feature/ComposeTheoryNativeContentTest.php`: повністю відновлена копія та незмінні вхідні моделі, вихідні/поточні атрибути сторінки, відсутній/дубльований/змінений блок, неправильний та початково відсутній subtitle, чужа чи відсутня сторінка або незавантажені блоки. Пошкодження приватного артефакта після успішного виклику та семантично неправильний пакет із правильним SHA перевірено для наступного виклику й незалежної `presentation()`. Є український smoke уроку й тесту в ізольованій SQLite.

На точній A: 9 тестів / 189 перевірок, exit 0. На B: 13 тестів / 209 перевірок, exit 0, разом із регресіями PERF‑18, compose і готовності курсу. В обох запусках — одне наявне попередження про застарілий атрибут PDO в PHP 8.5, без збоїв.

## Відповідність реальних маршрутів

Реальний Laravel HTTP kernel у PHP CLI, гостьовий стан, локальна MariaDB у транзакціях `READ ONLY`. Українська сторінка каталогу курсу на точній A повернула HTTP 200 і фактичний manifest з 254 уроками. Його точний знімок використовували для однаково прогрітого кешу manifest в окремій пам’яті кожного A/B-запуску; кеш активного сайту не змінювали.

Обидва уроки й пов’язаний тест повернули HTTP 200 на A і B. Повні впорядковані дані представлень і HTML збіглися побайтово: 16 і 12 відновлених блоків у двох уроках, 16 блоків сторінки й 84 питання в тесті. Перевірено заголовки, текст, навігацію, порядок, питання, відповіді, пояснення та дані оцінювання. Замість вилучення частин HTML використовували однакові ключ, CSRF і годинник лише в ізольованих процесах. Виключень із порівняння не було; штатний порядок тесту не змінювали.

## Профіль операцій

MariaDB 12.0.2, український HTTP kernel. У всіх профільованих A/B-запитах обробник власника повернув відновлену копію, а не проігнорував сторінку. Число викликів `binding()` дорівнювало числу очікуваних звичайних блоків; subtitle перевірявся окремо. Інші обробники повертали сторінку без входу у власну обробку.

Порівнювані піки — лише з чистої серії з однаковим прогрівом.

## Чисті парні заміри

Однакова локальна MariaDB, гостьовий стан і знімок прогрітого manifest для A/B, окремий прогрів кожного маршруту й кожної версії. Таймер вимірював `handle` + `terminate` Laravel HTTP kernel через PHP CLI, без старту PHP, підключення до БД, створення snapshot чи підстановки manifest у приватний кеш. ## Активна копія

До `gramlyze.loc` застосовано лише `TheoryNativeContentRelease.php`. Composer підтвердив фізичний файл і SHA‑256 B `84ce0e11b6007cfc5777c0b663e998d815cb255970704c1c7fbd5f424b03fcd4`. Контрольні суми успадкованих файлів PERF‑13–17, controller/manifest курсу і compose-controller залишились незмінні. Частину PERF‑18 у цьому ж класі збережено. У релізному маніфесті оновлено тільки SHA цього файла: 523/523 перевірок пройшли, SHA навчальних артефактів не змінювали.

У новому приватному вікні Opera на українській версії відкрився урок Parts of Speech, відобразилися блоки теорії (іменники, дієслова, прикметники). Кнопка «Змішаний тест» відкрила пов’язаний тест із 84 питаннями й початковим прогресом 0/84. Посилання в навігації тесту повернуло до каталогу English Grammar Theory Course. Відповіді в обслуговуваній копії не надсилали.

Діагностичні скрипти та копії з інструментацією прибрано. Робочу БД, контент, особистий прогрес, сесії, `.env` і `APP_KEY` не змінювали. Гілка PERF‑19 містить прийняті PERF‑13–18 і готова для ручного перенесення. `main`, `.ub` і production не змінювали.
