# PERF‑20 — пакетне дозавантаження зв’язків курсового тесту

База — PERF‑19, `b3abcf1d40e7e744d1f91ea93c8b7bd4412461ad`. Apache `gramlyze.loc` обслуговує `D:/DEV/htdocs/gramlyze.loc/public`; Git HEAD цього checkout — `41820a2bebdf69004fa7209a2a38457f93efabbd` із локально застосованими попередніми PERF. Checkout не перемикали й не скидали. Точний A: SHA‑256 `440c5825a0a89e02ee289969474c671fd305ff7506e32f2fd681b3364ba606ba`; файл Composer, served-копія та робоча гілка збігалися побайтово.

Усі запити — українські маршрути, без мовних префіксів і змін правил доступу:

- [Тест Parts of Speech](http://gramlyze.loc/courses/english-grammar-theory/lesson/basic-grammar/parts-of-speech/test): 4 банки, 84 питання (66 звичайних + 18 compose).
- [Тест One / Ones](http://gramlyze.loc/courses/english-grammar-theory/lesson/zaimennyky-ta-vkazivni-slova/one-ones/test): 3 банки, 54 питання (36 звичайних + 18 compose).
- [Урок Parts of Speech](http://gramlyze.loc/courses/english-grammar-theory/lesson/basic-grammar/parts-of-speech): контроль вмісту і посилань, 16 блоків.

## Причина та зміна

На точній A всі банки передавали в `withQuestionRelations()` звичайну `Illuminate\Support\Collection`. Для `SavedGrammarTest` resolver вже завантажив потрібні зв’язки: Parts of Speech — банки з 18/30/36 питаннями, One / Ones — із 18/36; повторних SQL у методі не було. На обох маршрутах `VirtualSavedTest` передавав 54 питання. Фільтр уже завантажив `category`, `answers.option`, `options`, `verbHints.option` і `source`, а `hints`, `chatgptExplanations` та `tags` читалися окремо по кожному питанню. Це 162 SELECT, а не всі SQL маршруту.

`app/Services/TheoryCourseTestPoolService.php` формує тимчасову Eloquent-колекцію над тими самими відібраними моделями `Question` і викликає `loadMissing()` один раз на банк. Не-`Question` і дублікати лишаються в початковій послідовності, з якої повертається `values()`. Питання не перечитуються; уже завантажені, зокрема порожні та вкладені, зв’язки не замінюються. Межі винятків, фільтр, глобальний resolver, добір, seed, перемішування, оцінювання й прогрес не змінені.

## SQL і відповідність

Локальна MariaDB 12.0.2, ізольований гостьовий Laravel HTTP kernel через PHP CLI, транзакції `READ ONLY`. Однакові відбитки джерел і фактичний знімок українського manifest PERF‑19; у вимірах окремий прогрітий array-кеш, без змін кешу сайту. SQL і кількість створених моделей зв’язків вимірювали окремо від чистої серії.

| Профіль запиту | Parts of Speech A → B | One / Ones A → B |
| --- | ---: | ---: |
| SQL усього | 226 → 67 | 211 → 52 |
| SQL підготовки пулу | 221 → 62 | 206 → 47 |
| SQL усього на `hints` / `chatgptExplanations` / `tags`, кожен тип | 57 → 4 | 56 → 3 |
| SQL дозавантаження трьох зв’язків віртуального банку | 162 → 3 | 162 → 3 |
| Рядки віртуального банку: підказки / пояснення / теги | 18 / 0 / 72, без змін | 18 / 0 / 18, без змін |
| Інструментований час пулу, мс | 3 890,18 → 426,60 | 1 966,23 → 397,25 |
| Інструментований пік активної пам’яті PHP, байти | 87 803 344 → 87 651 224 | 87 619 736 → 87 456 344 |

Решта категорій SQL незмінна. Для кожного зв’язку `54 × 1 ID → 1 × 54 ID` (для пояснень ключем є текст питання). На підмножинах 1/4/12 фактичних моделей отримано 3/12/36 SELECT на A та 3/3/3 на B. У цільовій SQLite-перевірці для 1/6 питань — 3/18 SELECT на A та 3/3 на B.

Обидва тести й контрольний урок повернули HTTP 200 на A/B. Усі впорядковані дані представлення й HTML збіглися побайтово без вилучення полів. Збіглися, зокрема, банки й порядок питань, правильні відповіді, варіанти, токени, підказки й пояснення, `source_test`, counts, completion і навігація. Для однакового HTML ключ, CSRF і час зафіксовано лише в ізольованих процесах; чинний детермінований порядок пулу не змінювали.

## Тести

`tests/Feature/TheoryCourseTestPoolRelationsTest.php` покриває Support/Eloquent, порожній набір, змішані значення, підготовлені та синтетичні моделі, повтор об’єкта й різні об’єкти з тим самим ID, частково завантажені відношення й вкладені опції, а також обидва види банків через фактичні фільтр і resolver. На точній A п’ять поведінкових тестів пройшли й одна нова SQL-перевірка відтворила зростання 3 → 18 SELECT. На B — 17 тестів і 330 перевірок, exit 0, включно з регресіями PERF‑19/18 і суміжним добором банків. Одне наявне попередження PHP 8.5 та очікувані попередження ізольованого кешу меню теорії.

## Чисті парні заміри

По шість пар AB/BA для кожного тесту, по одному нетаймованому прогріву на маршрут і версію. Межі таймера: `handle` + `terminate` Laravel HTTP kernel через PHP CLI; без PHP bootstrap, з’єднання з БД і завантаження знімка manifest. Профайлер, SQL-логування й інші власні навантаження були вимкнені. Усі зразки збережено приватно; це не час Apache чи браузера.

## Активна копія

На `.loc` застосовано лише `app/Services/TheoryCourseTestPoolService.php`. Composer підтвердив фізичний шлях і SHA‑256 B `292ec1993736b31b6c0a0dd673c04871410115c0fb470d74cacfd4d5b5aa8553`. До й після звірено файли PERF‑13–19, фільтр, resolver і контролери. Сервіс не входить до релізного маніфесту SHA; усі 523 перевірки пройшли без змін pin або артефактів.

Гостьовий Chromium запущено в новому ізольованому контексті, без профілю користувача, видимого вікна чи захоплення екрана. Урок, тест і каталог повернули HTTP 200 на основній українській версії. Тест відобразив 84 питання; складання правильної відповіді з токенів дало `1 / 84`, кнопка відкрила наступне питання. Після reload незавершений лічильник повернувся до `0 / 84`, а курс зберіг останній відкритий урок. Це чинна поведінка незміненого JS: незавершена спроба зберігається лише в пам’яті сторінки. Перший сценарій не знайшов посилання назад через невірне припущення про абсолютний href; окрема перевірка коректного відносного посилання підтвердила перехід до каталогу. Запитів із записом і помилок JS не зафіксовано.

Тимчасову діагностику прибрано, докази збережено приватно. Робочу БД, контент, особистий прогрес, сесії, `.env` та `APP_KEY` не змінювали. Гілка PERF‑20 успадковує PERF‑13–19 і готова для ручного перенесення; `main`, `.ub` і production не змінено.
