## Реалізація та пріоритет

[TheoryEditorialDescriptions](../../app/Support/TheoryEditorialDescriptions.php) — невеликий versioned словник українських plain-text описів, окремий від TextBlocks. Ключ — повний збережений `Page.seeder` + локаль `uk`. Унікальність усіх 43 ключів підтверджена локальним read-only контекстом; локальні числові ID, короткий slug, display title, host, query, Referer і cookie не є ключем.

[PageMetadata::theory](../../app/Support/PageMetadata.php) отримав необов’язкові scalar-параметри seeder/locale. Пріоритет: придатний український intro за чинними M5 правилами → зареєстрований редакційний опис → старий загальний fallback. Український intro, доданий пізніше, автоматично матиме перевагу. Unknown identity й EN/PL не отримують override.

[theory/show](../../resources/views/theory/show.blade.php) передає `getRawOriginal('seeder')` лише для реальної `Page.type=theory` всередині наявної UK-гілки. Контролери, маршрути й визначення локалі не змінені. Додаткових SQL, завантаження question banks, читання всіх definitions на GET або AI API немає. Definitions читає лише локальний діагностичний інструмент/автотести, не formatter.

Збережено Blade sections, plain-text обробку та escaping. Змінюється лише meta description і його стандартне успадкування в og:description/twitter:description. Свідомі social overrides, title/og:title/twitter:title/H1 не змінюються.
