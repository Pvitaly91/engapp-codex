## Editorial changes and design boundary

The infinitive lesson keeps all four useful source groups, distinguishes own action/object performer/clause alternatives, promise recipient versus performer, main-verb versus infinitive negation, and intention versus actual completion. Semantic grouping remains a mnemonic, not a complement-selection algorithm. Valid alternative preposition/-ing and passive-need patterns are not blanket errors.

The meaning-change lesson has five explicit contrasts, one for each target verb. It separates reported completion/reminders/questions, missed action/later completion, effort/method/outcome, and ordinary regret/formal announcement. Criteria are visible before answering; grammatical-but-noncompliant answers receive a precise explanation rather than a false blanket grammar ban.

The used-to lesson distinguishes familiarity, acquiring familiarity and former regular actions/states. It covers present/past/future situations, questions, negatives and short answers; familiarity is not liking, mastery or necessarily slow adaptation. `did use to` is not mechanically transferred to `did get used to`.

All full English teaching examples have Ukrainian translations. Comparison-table fields distinguish examples/translations from commentary. Existing useful source content, clarifications, new additions and replaced examples are individually mapped in the editorial companion. Publisher editorial body, indexed excerpt, inaccessible page and learner comment are not conflated. Review was agent/editorial review, not a claimed external human certification. No external exercise bank was copied; no ranking/CTR/volume guarantee is claimed.

The existing canonical pipeline, Blade, CSS, typography, spacing, semantic accents, examples, header/sidebar and practice engine were retained. Six continuing slots per lesson preserve UUID, order, level, column, type and anchors. Infinitive retains forms-grid; both comparative lessons retain comparison-table. Navigation retains eight items per lesson. One B1 practice-set is appended per owner; no metadata transition.
