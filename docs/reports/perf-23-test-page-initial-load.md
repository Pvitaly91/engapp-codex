## Критерії A/B

Мінімум для реалізації: 15% менша медіана повного HTTP TTFB при **першому вході на Word Order Step**, ціль 20%; напрямок ефекту має підтвердитися в обох порядках A/B/B/A і B/A/A/B. Не підміняємо його лише прибутком усередині PHP-методу або SQL. Підтверджене істотне зростання хвоста (орієнтири 10% і 50 мс у повторних зіставних вимірах), зміна контракту або прогресу — підстава не застосовувати кандидат. Перший GET, повтор і відновлення після синтетичної відповіді перевіряються окремо. Відхилення у коротких серіях контролів перевіряються з урахуванням зафіксованого A/A, а не оголошуються незалежно стабільним ефектом.

### Незалежна перевірка RNG і повного контракту

У додатковій серії лише для паритету використано спільний seed для PHP, приватну підстановку Laravel `Arr` Randomizer та погоджені session seed-и MariaDB. Це не змінює застосунок, SQL-порядок у робочому середовищі або методику часового A/B. На всіх 12 UK/EN/PL маршрутах **36/36** пар first/repeat/resume: ідентичні HTML після тільки двох описаних нормалізацій, точні JSON і порядок/UUID питань, рівні, типи, правильні відповіді, опції, підказки, локаль та стан. HTTP-контракт і **24/24** ізольованих відновлення пройшли. Разом із нативною серією — **99/99** точних пар. Початковий A/A з однією лише CSRF-нормалізацією не перезаписано; джерело решти різниці точно встановлено як похідний від тимчасового ключа URL Livewire.

У цій окремій серії перший A-запит на прогріві виконався за 45,21 с, з них 30,42 с bootstrap; B-прогрів — 3,42 с. Обидва завершені, контракт збігся.
