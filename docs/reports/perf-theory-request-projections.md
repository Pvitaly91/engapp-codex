## Один механізм-кандидат

Кандидат змінює лише `app/Support/TheoryNativeContentRelease.php`. У приватному шляху `binding()/validDesign()` після **кожного** повного implicit-root `load()` validator викликає чистий serializer через `projectDefinition`. Усі умови `validate`, а також звірки поточного UUID/type/column/heading/level/CSS/body/owner/locale та practice контракти залишаються активними. Публічні `definition` і `validate`, explicit roots і CLI продовжують обчислювати напряму. Не кешується валідація, binding, Eloquent, прогрес, generated HTML або помилки. Виклик, що не підходить для memo, виконує старе обчислення.

У точному B2: ключ `SHA-256(serialize([application base path, full profile, lesson, before]))` у просторі цієї класової операції. Немає сортування або ключів тільки за owner/object ID. SHA перевірки джерел не замінено цим ключем. Вхід — уже перевірені JSON value trees і trusted PHP profile; при іншому `serialize_precision` — старий шлях. Лише `theory.show` GET/HEAD, UK, не CLI. Результат успішного чистого обчислення — PHP value array (copy-on-write); як у M42/PERF-02, місце збереження — атрибути поточного Request, але тут зберігається не артефакт, а результат чистої проєкції, і додатково перевіряються слабкі посилання на app і request. Навіть копія Request із перенесеними attributes не успадковує його. LRU максимум 12 entries, сумарно 256 KiB за розмірами серіалізованих retained values (не вимір PHP heap); вхід понад 128 KiB або результат, що не вміщається, не кешується. Звичайний miss виконує оригінальне обчислення, навіть за заповненого ліміту. Перед точним B2 випробували той самий механізм із ширшим лімітом B1 (`61b13693ddc5d83b1d43a797d678bc7a107031b42fa6cb739ecc7682a9d7d6a1`); peak зріс на 714464 / 836064 / 832720 B, і цю версію не залишали. ## Еквівалентність і ізоляція проєкцій

Незалежний BEFORE зафіксовано до редагування з exact SHA A. Повні scalar-array і body bytes 18 прийнятих уроків (M84 native/point details, M77 exact legacy boxes, M78 captured absent subtitle/continuing UUID) спершу збіглися з незалежними frozen after definitions. Потім так само перевірено B2, включно з окремими same-owner змінами значень, типів, порядку й маркерів.

На точному B2 фокусна ізольована серія: **12 виконань, 240 assertions, 0 failures/errors, 1 skip**. Покрито hit/miss, розмежування lesson / before / profile / root / app, copy-on-write повернутого значення, malformed/failed computation, два ліміти й eviction, два routed GET в одному PHP kernel і Request duplicate з успадкованими attributes, CLI/explicit-root/нецільовий route method/locale та відмінну precision. Для поточних навчальних блоків і frozen artifacts перевірки знову відхиляють змінений source/owner/UUID/type/locale/body, неправильний SHA й malformed JSON; новий request не приховує зміни джерела. Тест самого byte-identical symlink пропущено через відсутність можливості створити symlink із цього процесу; інші guards не ослаблені. Одна відома PHP 8.5 deprecation не є новим збоєм.
