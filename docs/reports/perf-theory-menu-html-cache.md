## До / після

Раніше урок і категорія готували повне дерево моделей, а sidebar робив ще один запит за відрендереним desktop HTML; mobile окремо будував дерево зі своїм active state. Тепер команда отримує **свіже** дерево через той самий алгоритм видимості, вкладеності й порядку, обходячи обидва годинні кеші. Назви локалізуються штатним механізмом і екрануються у Blade. Маршрути відносні. Build валідує пари варіантів, стабільні ID, відсутність персонального стану та точність посилань.

Desktop віддає готове дерево в початковому HTML, без завантажувача та запиту за ним. Mobile запитує ту саму ревізію при першому відкритті; повторне відкриття не замінює DOM. Запит без ревізії обирає поточний або попередній доступний випуск; запит за конкретною ревізією не може отримати іншу. Успішні відповіді мають ETag; режим development зберігає свій `no-store`, production-профіль — приватну перевірку свіжості. У production-профілі HTML уроку/категорії теж перевіряється на свіжість, щоб нове відвідування не трималось за стару ревізію.

На сторінці окремо передаються лише ID поточного уроку й категорії. У браузері визначаються aria-current, батьківські гілки, пошук та прокручування. Стан згортання зберігається як раніше в localStorage. Зміст, теги й основні дані сторінки лишаються поза знімком. Категорія зберігає запити для власних карток, підрахунку уроків і тематичних тестів, а не для повного меню.

Публікація бере міжпроцесне блокування на mode/locale/family, готує й перевіряє staging, встановлює новий каталог випуску і перейменовує завершений файл активації **на нове ім’я у тій самій директорії**. Попередній файл не замінюється і не видаляється. Перевірено реальне змагання двох PHP-процесів на Windows; окремо в локальному Ubuntu WSL/ext4 — двоє writer-процесів і 30 читань файлового протоколу. Це перевірка видимості завершеного випуску, не гарантія від втрати живлення й не запуск Laravel на production/Linux. HTTP не генерує меню. Читання перевіряє розмір/доступність пари; для точного URL перевіряється SHA тільки запитаного варіанту; `--check` перевіряє обидва повністю. Пошкоджений або відсутній кеш дає попередню придатну пару або доступне «Усі теми», із записом у журнал.

## Вимірювання

Windows / XAMPP / PHP 8.5, локальний loopback, гість без автентифікації, UK, APP_DEBUG=false, identity encoding, одна контрольована тепла гостьова сесія на фазу, послідовні запити. Дані наведено окремо для повної відповіді й меню; приватні сирі заміри не додаються до Git. Медіана / p95, мілісекунди, 20 успішних вимірювань у кожній порівнюваній серії.

Абсолютний browser paint timestamp не виміряно.

## Приймання

- PHP: **25 тестів, 481 assertion** без невдалих. Ізольована SQLite; відомий не пов’язаний PHP 8.5 deprecation `PDO::MYSQL_ATTR_SSL_CA` у `config/database.php`. Перевірено свіжі назви/порядок попри старий кеш, дозволені мови й ізольований production mode, контекст і відсутність персональних атрибутів, незмінну ревізію, помилку та відкат, одночасні builds, читання старої ревізії, пошкодження/відсутність, traversal, canonical URL, відсутність menu SQL/Blade у endpoint.
- JS: **12** тестів меню/пошуку (включно з повторною ініціалізацією та BFCache) і **7** тестів геометрії sidebar. Нових JS-помилок у перевіреному браузерному сценарії не виявлено.
- Реальний HTTP: точна UK revision, ETag дорівнює SHA тіла, If-None-Match → 304 / 0 B, старі page/category параметри не змінюють байти, невідомі variant/revision → 404. Запит на desktop зі старого URL залишився сумісним, але сторінки його не роблять.
- Браузер: 1440 / 390 / 320 px, світла/темна тема, UK/EN/PL; пошук звузив 24 верхні гілки до 1 і повернув 24 після очищення. Розкриття категорій, активний вкладений урок та активна категорія без уроку; автопрокрутка, ширини 410/116 px на desktop і відновлення після reload; теорія → тест → Back, Forward без нав’язування sidebar тесту. Дублів ID **у меню** немає; на сторінці є давній окремий `grad` у SVG логотипах header/footer, ці компоненти не змінювались. На 320 px контейнер меню залишився в межах viewport; для довгих назв усередині списку спостерігалось горизонтальне прокручування, окремий редизайн не робився.
- 390 px, один браузерний замір від кліку до видимого поля пошуку: first open **1291 → 317 ms**, reopen **275 → 278 ms**. Повторне відкриття зберегло одну копію дерева; точне мережеве число для нього підтверджує JS-тест, не ресурсний таймер браузера.
- Fallback/доступність: перевірено резервний HTML, відсутність JS у знімках і `noscript` з робочим посиланням на каталог. Окрему live-сесію з повністю вимкненим JavaScript не перевірено; no-JS PASS не заявляється. Повний production Laravel не запускався.
