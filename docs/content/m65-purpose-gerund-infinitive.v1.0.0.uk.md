## Purpose: to / in order to / so that

[Локальна сторінка](http://gramlyze.loc/theory/clauses-and-linking-words/purpose-to-in-order-to-so-that)

Purpose: to / in order to / so that — як назвати мету, зберегти виконавця та відрізнити намір від уже відомого результату.

### purpose-hero

level: B1-B2

Вступ: Мета відповідає на «навіщо?». To / in order to + базова форма стисло називають потрібну дію; so that + підмет + присудок дозволяє явно назвати виконавця й можливість або бажаний стан. Названа мета ще не означає, що її досягнуто.

**Основне 1**

Позначка: КОРОТКА МЕТА

color: emerald

text: У простій активній моделі обидві дії має виконати той самий учасник.

example: Oleh stopped to read the sign.
Олег зупинився, щоб прочитати знак.

**Основне 2**

Позначка: ВИКОНАВЕЦЬ МЕТИ

color: blue

text: So that може називати іншого або того самого виконавця.

example: Oleh stopped so that I could read the sign.
Олег зупинився, щоб я міг прочитати знак.

**Основне 3**

Позначка: НЕГАТИВНА МЕТА

color: amber

text: In order not to називає те, чого прагнуть уникнути.

example: We spoke quietly in order not to disturb Olia.
Ми говорили тихо, щоб не турбувати Олю.

### Як побудувати мету

Заголовок: Як побудувати мету

Вступ: Після інфінітивного to ставимо базову форму дієслова разом із потрібними доповненнями. In order to частіше трапляється в письмі або виразно позначає мету; воно не «правильніше» за to.

**Пункти 1**

Позначка: TO

Заголовок: головна дія + to + базова форма

Пояснення: Oleh opened the box to check the number.
Олег відкрив коробку, щоб перевірити номер.
Номер перевіряє Олег. Check the number — повна група; не відкидай додаток.

**Пункти 2**

Позначка: IN ORDER TO

Заголовок: головна дія + in order to + базова форма

Пояснення: We moved closer in order to see the map.
Ми підійшли ближче, щоб побачити карту.
Мету можна подати й коротшим to see the map — щоб побачити карту.

**Пункти 3**

Позначка: НЕГАТИВНА МЕТА

Заголовок: in order not to / so as not to + базова форма

Пояснення: I turned the music down in order not to disturb Anna.
Я стишив музику, щоб не турбувати Анну.
So as not to disturb Anna також означає «щоб не турбувати Анну». Заперечено мету, не дію стишування.

**Пункти 4**

Позначка: SO THAT

Заголовок: so that + підмет + присудок

Пояснення: She left a note so that I could find the key.
Вона залишила записку, щоб я міг знайти ключ.
Залишила вона; знайти ключ мав я. Після so that потрібна повна частина, не лише інфінітив.

### Виконавець, модальність і бажаний результат

Заголовок: Виконавець, модальність і бажаний результат

**Пункти 1**

Позначка: Той самий або інший виконавець

color: emerald

Пояснення: З тим самим виконавцем можливі і просте to, і so that. Друга модель корисна, коли хочемо прямо назвати можливість. Змінивши підмет у so that-частині, змінюємо того, хто має виконати дію мети.

**Приклади 1**

EN: I moved the lamp to read the label.

UK: Я пересунув лампу, щоб прочитати етикетку.

**Приклади 2**

EN: I moved the lamp so that I could read the label.

UK: Я пересунув лампу, щоб я міг прочитати етикетку.

**Приклади 3**

EN: I moved the lamp so that Olia could read the label.

UK: Я пересунув лампу, щоб Оля могла прочитати етикетку.

Примітка: Це опис простої активної моделі, не заборона всіх інших конструкцій. Наприклад: Here is a place for the children to play.
Ось місце, де діти можуть гратися.
For the children to явно називає дітей; це інша модель.

**Пункти 2**

Позначка: Обери потрібне значення, не автоматичний modal

color: blue

Пояснення: Can/could називають можливість у цій ситуації; will/would можуть передавати бажаний майбутній стан або уникнення події. Час і задум визначають форму; so that не вимагає модального дієслова завжди.

**Приклади 1**

EN: I will send the map today so that you get it before Friday.

UK: Я надішлю карту сьогодні, щоб ти отримав її до п’ятниці.

**Приклади 2**

EN: I will send the map today so that you will have it before Friday.

UK: Я надішлю карту сьогодні, щоб до п’ятниці вона була в тебе.

Примітка: Present simple і will тут можливі. Не перенось загальне навчальне правило для when/if на всі so that-частини. У неформальному мовленні that часто опускають: I brought a torch so we can see the path.
Я приніс ліхтарик, щоб ми могли бачити стежку.

**Пункти 3**

Позначка: Що заперечуємо і чи досягнуто мети

color: amber

Пояснення: Негативна мета описує небажану подію. Вона не заперечує головну дію і не доводить успіху наміру. У so that-частині not стоїть у її власній дієслівній моделі.

**Приклади 1**

EN: I wrote the address down so that I would not forget it.

UK: Я записав адресу, щоб не забути її.

**Приклади 2**

EN: I did not open the door because the baby was asleep.

UK: Я не відчинив двері, бо дитина спала.

Примітка: У першому реченні запис зроблено, але не відомо, чи адресу згодом не забули. У другому заперечено відчинення; because називає причину.

### Мета дії, призначення речі чи наслідок

Заголовок: Мета дії, призначення речі чи наслідок

Вступ: Однакові слова не гарантують однакового зв’язку. Спочатку визнач, що саме стверджує мовець.

**Колонки 2**

**cells 2**

**cells 3**

**Рядки 2**

**cells 1**

Функція предмета

**cells 2**

**cells 3**

**Рядки 3**

**cells 1**

**cells 2**

Я пішов до магазину по молоко.

**cells 3**

Після for — іменникова група some milk, не базове дієслово.

**Рядки 4**

**cells 1**

Відомий наслідок

**cells 2**

Полиця була запилена, тому я її витер.

Уточнення: So (that) може виражати мету, а в іншому контексті so/so that — наслідок. Тут намір і відомий результат задані явно. Дивись також Result та загальну будову To-Infinitive.

### Перевір модель і ролі

Заголовок: Перевір модель і ролі

**Пункти 1**

Позначка: БАЗОВА ФОРМА

color: rose

Заголовок: Після інфінітивного to потрібна базова форма.

wrong_en: She went to the shop to bought some milk.

wrong_ua: Задум: вона пішла до магазину по молоко.

right_en: She went to the shop to buy some milk.

right_ua: Вона пішла до магазину, щоб купити молоко.

Примітка: Минулий час виражено went; buy не стає bought. Some milk залишається потрібним додатком.

**Пункти 2**

Позначка: ПОВНА ЧАСТИНА

color: amber

Заголовок: Не губи виконавця після so that.

wrong_en: She left a note so that could find the room.

wrong_ua: Задум: записку залишила вона, знайти кімнату мав я.

right_en: She left a note so that I could find the room.

right_ua: Вона залишила записку, щоб я міг знайти кімнату.

Примітка: I називає потрібного виконавця. To find без цього I змінило б ролі у простій моделі.

**Пункти 3**

Позначка: ОСОБИСТА МЕТА

color: sky

Заголовок: Умова: людина взяла ключ саме з наміром відчинити двері.

wrong_en: I took the key for open the door.

wrong_ua: Задум: я взяв ключ, щоб відчинити двері.

right_en: I took the key to open the door.

right_ua: Я взяв ключ, щоб відчинити двері.

Примітка: For open не підходить. Для цієї особистої мети вживаємо to open; конструкції for + іменник і for + -ing мають свої правильні вживання.

Уточнення: Питання й заперечення будуються за головною конструкцією: Did you come to collect the book?
Ти прийшов забрати книжку?
I did not come to collect the book; I stayed at home.
Я не прийшов забрати книжку: я залишився вдома.
У другому прикладі контекст явно заперечує прихід. Це не те саме, що прийти з негативною метою.

### Короткий підсумок

Заголовок: Короткий підсумок

**Пункти 1**

Мета — те, чого прагнуть, а не автоматично вже досягнутий результат.

**Пункти 2**

To / in order to + базова форма можуть мати потрібні додатки й обставини.

**Пункти 3**

So that + підмет + присудок явно зберігає виконавця; він може бути тим самим або іншим.

**Пункти 4**

Для негативної мети є in order not to, so as not to та so that ... not. Не плутай їх із запереченням головної дії.

**Пункти 5**

For + іменник, функція речі з for + -ing і особиста мета з to — різні корисні моделі.

## Gerund

[Локальна сторінка](http://gramlyze.loc/theory/verb-patterns/gerund)

Gerund — форма на -ing, яка може називати заняття, бути підметом або доповнювати певне дієслово чи прийменник.

### gerund-hero

level: A2-B1

Вступ: Gerund — навчальна назва форми на -ing, коли дія виступає темою або доповненням. Вона може мати власний додаток. Саме закінчення -ing не означає «прямо зараз», і не кожне -ing слово є герундієм.

**Основне 1**

Позначка: ДІЯ ЯК ТЕМА

color: emerald

text: Називаємо заняття, про яке щось повідомляємо.

example: Drawing maps takes time.
Малювання карт потребує часу.

**Основне 2**

Позначка: ПІСЛЯ ПЕВНОГО ДІЄСЛОВА

color: blue

text: Запам’ятовуй модель разом із головним дієсловом.

example: I enjoy drawing maps.
Мені подобається малювати карти.

**Основне 3**

Позначка: ПІСЛЯ ПРИЙМЕННИКА

color: amber

text: Коли прийменник доповнюємо дією в цій моделі, використовуємо -ing.

example: She left without saying goodbye.
Вона пішла, не попрощавшись.

### Форма -ing і потрібні доповнення

Заголовок: Форма -ing і потрібні доповнення

Вступ: У reading this book — «читання цієї книжки» — форма reading зберігає додаток this book. Подібність до іменника за роллю не стирає всіх дієслівних властивостей.

**Пункти 1**

Позначка: ЗВИЧАЙНЕ -ING

Заголовок: work → working; read → reading

Пояснення: Reading this book takes time.
Читання цієї книжки потребує часу.
Work — працювати, working — робота як дія; read — читати, reading — читання.

**Пункти 2**

Позначка: КІНЦЕВЕ -E

Заголовок: make → making; see → seeing

Пояснення: Make — робити; making — форма цього дієслова на -ing: прибираємо кінцеве німе e. See — бачити; seeing — форма на -ing, у якій -ee зберігаємо. Це не правило «видаляй будь-яке e».

**Пункти 3**

Позначка: ПОДВОЄННЯ

Заголовок: swim → swimming; visit → visiting

Пояснення: Swim — плавати; swimming — плавання. У короткому swim подвоюємо m після короткого голосного. Visit — відвідувати; visiting — відвідування: наголос не на останньому складі, t не подвоюємо.

**Пункти 4**

Позначка: -IE ТА -Y

Заголовок: lie → lying; study → studying

Пояснення: Lie — лежати; lying — лежання: -ie змінюємо на -y перед -ing. Study — вчитися; studying — навчання: y перед -ing залишаємо.

### Де працює gerund

Заголовок: Де працює gerund

**Пункти 1**

Позначка: Підмет, а не будь-яке -ing

color: emerald

Пояснення: Коли одне заняття є темою речення, у простому прикладі узгоджуємо присудок з одниною. Continuous із be описує дію в перебігу, а прикметникове -ing характеризує предмет.

**Приклади 1**

EN: Painting the door takes time.

UK: Фарбування дверей потребує часу.

**Приклади 2**

EN: Olia is painting the door.

UK: Оля зараз фарбує двері.

**Приклади 3**

EN: That was a boring film.

UK: То був нудний фільм.

Примітка: У першому реченні painting the door — тема. У другому is painting — Continuous. У третьому boring описує фільм, а не називає заняття.

**Пункти 2**

Позначка: Модель після дієслова

color: blue

Пояснення: Корисні моделі: enjoy — отримувати задоволення від; avoid — уникати; mind — заперечувати проти; finish — закінчувати; keep — продовжувати. Коли ці дієслова в наведеній моделі доповнюємо іншою дією, використовуємо -ing.

**Приклади 1**

EN: She enjoys reading on the train.

UK: Їй подобається читати в поїзді.

**Приклади 2**

EN: We finished writing the report at noon.

UK: Ми закінчили писати звіт опівдні.

**Приклади 3**

EN: He keeps checking the time.

UK: Він раз у раз перевіряє час.

Примітка: Закінчення -s має enjoys/keeps, не reading/checking. Це конкретні моделі, не перелік усіх можливих словникових конструкцій. Like/love/start можуть допускати й інфінітив; не відкидай його без умови.

**Пункти 3**

Позначка: Дія після прийменника

color: amber

Пояснення: Прийменник може мати іменник або займенник. Якщо тут його доповненням є дієслово, беремо -ing: interested in learning — зацікавлений у навчанні; after leaving — після виходу.

**Приклади 1**

EN: I am interested in learning Italian.

UK: Я зацікавлений у вивченні італійської.

**Приклади 2**

EN: After reading the note, I called Olia.

UK: Прочитавши записку, я подзвонив Олі.

Примітка: To теж буває прийменником: I am used to reading on the bus.
Я звик читати в автобусі.
I want to read on the bus.
Я хочу читати в автобусі.
У want to read слово to належить інфінітиву. Повний контраст звички є в окремому уроці.

**Пункти 4**

Позначка: Заперечення, питання й час

color: slate

Пояснення: Not перед -ing заперечує саме цю дію; not при головному дієслові має іншу область. Питання утворюємо через головне дієслово, а час визначає воно та контекст.

**Приклади 1**

EN: I do not enjoy working on Sundays.

UK: Мені не подобається працювати в неділю.

**Приклади 2**

EN: I enjoy not working on Sundays.

UK: Мені подобається не працювати в неділю.

**Приклади 3**

EN: Do you enjoy drawing?

UK: Тобі подобається малювати?

Примітка: Enjoy drawing не стверджує, що людина малює зараз. У mind перевір значення всієї відповіді: Do you mind waiting here? — No, that is fine.
Ти не проти почекати тут? — Ні, це мене влаштовує.
Do you mind waiting here? — Yes, I do. I have to leave now.
Ти не проти почекати тут? — Так, я проти. Мені треба йти зараз.

**Приклади 2**

**Приклади 3**

Примітка: Не роби з першого речення висновку, що олівець у мовця в руці саме зараз. Perfect і Passive Gerund мають окремі уроки; вони не потрібні для цієї A2 відмінності.

## To-Infinitive

[Локальна сторінка](http://gramlyze.loc/theory/verb-patterns/to-infinitive)

To-Infinitive — to + базова форма дієслова після певних слів, у моделі з виконавцем та для позначення мети.

### infinitive-hero

level: A2-B1

Вступ: To-infinitive = to + базова форма: to go — піти, to be — бути, to have — мати. Інфінітив може мати додаток і бути частиною бажання, рішення, оцінки чи мети. Це не окремий майбутній час і не завжди відповідь на «навіщо?».

**Основне 1**

Позначка: ФОРМА НЕ УЗГОДЖУЄТЬСЯ

color: emerald

text: Головне дієслово змінюється, інфінітив залишається базовим.

example: She wants to read this book.
Вона хоче прочитати цю книжку.

**Основне 2**

Позначка: ХТО МАЄ ДІЯТИ

color: blue

text: У want someone to виконавця називаємо окремо.

example: She wants me to read this book.
Вона хоче, щоб я прочитав цю книжку.

**Основне 3**

Позначка: НЕГАТИВНА ФОРМА

color: amber

text: Навчальна базова модель — not to + дієслово.

example: We decided not to leave.
Ми вирішили не йти.

### To + базова форма: будова й питання

Заголовок: To + базова форма: будова й питання

Вступ: Після to не додаємо -s через he/she/it і не ставимо минулу форму лише тому, що головна дія минула. Потрібні доповнення зберігаємо.

**Пункти 1**

Позначка: БАЗОВА ФОРМА

Заголовок: головне дієслово + to + базова форма

Пояснення: He wanted to open the box.
Він хотів відкрити коробку.
Wanted називає минуле бажання; open не змінюється на opened. Не відомо, чи коробку відкрили.

**Пункти 2**

Позначка: ЗАПЕРЕЧЕННЯ

Заголовок: головне дієслово + not to + базова форма

Пояснення: She decided not to send the letter.
Вона вирішила не надсилати листа.
Not стосується надсилання. Інфінітив зберігає додаток the letter.

**Пункти 3**

Позначка: ПИТАННЯ З WANT

Заголовок: Do / Does + підмет + want to ...?

Пояснення: Do you want to sit here?
Ти хочеш сісти тут?
Питання утворює головна конструкція; сам інфінітив не інвертуємо.

**Пункти 4**

Позначка: ПИТАННЯ З BE

Заголовок: Is it + прикметник + to ...?

Пояснення: Is it difficult to find the office?
Офіс важко знайти?
It is / is it належить головній конструкції; to find не змінюємо.

### Основні функції інфінітива

Заголовок: Основні функції інфінітива

**Пункти 1**

Позначка: Після певного дієслова

color: emerald

Пояснення: Want — хотіти; hope — сподіватися; decide — вирішувати; plan — планувати; promise — обіцяти; refuse — відмовлятися. Запам’ятовуй кожну модель. У want to інфінітив передає зміст бажання; це не окрема мета іншої дії.

**Приклади 1**

EN: We decided to stay at home.

UK: Ми вирішили залишитися вдома.

**Приклади 2**

EN: I hope to see you soon.

UK: Сподіваюся скоро тебе побачити.

**Приклади 3**

EN: She refused to answer the question.

UK: Вона відмовилася відповідати на запитання.

Примітка: Порівняй виконавця: I want to open the door.
Я хочу відчинити двері.
I want you to open the door.
Я хочу, щоб ти відчинив двері.
Object you потрібен у другій моделі want; не додавай його автоматично після кожного дієслова списку. Обіцянка чи відмова самі по собі не описують усе подальше виконання.
I can help.
Я можу допомогти.
Після can/must у базовій активній моделі стоїть форма без to. У I go to school. — Я ходжу до школи. — to є прийменником напрямку, не частиною інфінітива.

**Пункти 2**

Позначка: Мета — лише одна з функцій

color: blue

Пояснення: Коли інфінітив пояснює, навіщо виконано головну дію, він називає мету. Дві виконані події з and — інше повідомлення. У прикладах нижче не змінюємо виконавицю чи предмет.

**Приклади 1**

EN: She went to the kitchen to make coffee.

UK: Вона пішла на кухню, щоб приготувати каву.

**Приклади 2**

EN: She went to the kitchen and made coffee.

UK: Вона пішла на кухню й приготувала каву.

Примітка: У першому повідомлено мету приходу; приготування не підтверджено. У другому повідомлено обидві події. Докладно про мету: Purpose.

**Пункти 3**

Позначка: Після прикметника: значення й ролі

color: amber

Пояснення: Інфінітив додає потрібну інформацію в конкретній моделі, але не кожний прикметник вимагає його. Happy to help — радий допомогти; it is important to understand — важливо зрозуміти.

**Приклади 1**

EN: I am glad to help you.

UK: Я радий допомогти тобі.

**Приклади 2**

EN: It is important to understand this rule.

UK: Важливо зрозуміти це правило.

**Приклади 3**

EN: This text is easy to understand.

UK: Цей текст легко зрозуміти.

Примітка: У glad to help допомагаю я. В easy to understand текст розуміють інші; не додавай повторне it. I am happy.
Я щасливий.
The bag is heavy.
Сумка важка.
Ці речення можуть бути повними й без інфінітива.

**Пункти 4**

Позначка: Too / enough та потрібний предмет

color: slate

Пояснення: Too означає надмірність для названої дії в конкретних умовах; enough — достатність. Після something інфінітив може пояснювати, що з цим робити.

**Приклади 1**

EN: For Olia today, this box is too heavy to carry.

UK: Сьогодні для Олі ця коробка надто важка, щоб її нести.

**Приклади 2**

EN: The room is warm enough to work in.

UK: У кімнаті достатньо тепло, щоб у ній працювати.

**Приклади 3**

EN: I need something to read.

UK: Мені потрібно щось почитати.

Примітка: Оцінка коробки стосується Олі сьогодні, не всіх людей у світі. У room ... work in прийменник in зберігає потрібний зв’язок «працювати в кімнаті».

Уточнення: Не зливай заперечення: We did not decide to leave.

We decided not to leave.

Це різні повідомлення про рішення. У базовій моделі вчимо not to, але не оголошуємо будь-який прислівник між to та дієсловом неграматичним.

### Короткий підсумок

Заголовок: Короткий підсумок

**Пункти 1**

To-infinitive — to + базова форма з потрібними доповненнями; час і узгодження часто задає головне дієслово.

**Пункти 2**

Після певних дієслів інфінітив називає бажану або заплановану дію; want someone to окремо позначає виконавця.

**Пункти 3**

Інфінітив може доповнювати прикметник, іменник або something. Не кожний прикметник потребує такого доповнення.

**Пункти 4**

Мета з to не тотожна двом виконаним діям з and. Зберігай задум під час виправлення.

**Пункти 5**

Not при головному дієслові та not to мають різну область. Порівняй Gerund і Bare Infinitive; складні passive/perfect форми — окремі уроки. Passive Infinitive — не частина цієї A2 практики.
