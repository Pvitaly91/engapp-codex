# M46 — авторський master 1.0.1

Редакторська версія трьох UK уроків. Нативні компоненти, 18 завдань. Дата: 2026-10-11.

## Zero Conditional

Zero Conditional: як описувати закономірності, звичні реакції й правила. Форми, заперечення, питання, відмінність від First Conditional та вправи.

### zero-hero · hero

Zero Conditional описує зв’язок, який зазвичай повторюється: за певної умови отримуємо типовий результат. Це може бути закономірність, особиста звичка або правило конкретної системи — не обов’язково істина без винятків.

**ЗАКОНОМІРНІСТЬ**

Говоримо не про один випадок, а про типовий зв’язок умови й результату.

If ice gets warm enough, it melts.
Якщо лід достатньо нагрівається, він тане.

**ЗВИЧНА РЕАКЦІЯ**

Особиста звичка не має бути універсальною для всіх людей.

If I drink coffee late, I don't sleep well.
Якщо я п’ю каву пізно, то погано сплю.

**ПРАВИЛО ЧИ ВКАЗІВКА**

Опис того, що відбувається, відрізняй від наказу, що треба зробити.



### 1. Форма: умова й результат · forms-grid

Базова модель: if + Present Simple, Present Simple. Умова пояснює, коли спрацьовує результат. Закінчення -s та допоміжні do/does працюють як у звичайному Present Simple.

**Ствердження — if + умова, результат**

В обох частинах — Present Simple.

Умова → результат

if + підмет + дієслово, підмет + дієслово

З he/she/it додаємо -s або -es до звичайного дієслова.

If you press this button, the machine starts.
Якщо натиснути цю кнопку, машина запускається.

**Заперечення в умові — if + підмет + don't / doesn't + дієслово**

Після doesn't основне дієслово без -s.

Умова із запереченням

if + підмет + do/does not + базова форма, результат

Заперечуй саме ту частину, яка не відбувається.

If the scanner doesn't detect a page, it stops.
Якщо сканер не виявляє сторінку, він зупиняється.

**Заперечення в результаті — результат: підмет + don't / doesn't + дієслово**

Умова може залишатися ствердною.

Негативний результат

if + умова, підмет + do/does not + базова форма

З be використовуємо am/is/are not, а не do/does.

If the battery is empty, the sensor doesn't work.
Якщо батарея розряджена, датчик не працює.

**Питання — do / does + підмет + дієслово + if + умова?**

Питальне слово, якщо воно потрібне, ставимо перед do/does. В if-частині зберігаємо порядок твердження.

Питання про звичну дію

питальне слово + do/does + підмет + базова форма + if + умова?

Коротка відповідь повторює do/does.

Do you call reception if you need help? — Yes, I do.
Ти телефонуєш на рецепцію, якщо потрібна допомога? — Так.

### 2. Коли вживаємо Zero Conditional · usage-panels

**Звичка або повторювана реакція · blue**

Описуємо те, що людина зазвичай робить за певної умови. Це характеристика її поведінки, а не обіцянка на завтра.

If she goes to bed late, she is tired in the morning.

Якщо вона лягає пізно, то вранці втомлена.

If we take the bus, we usually arrive on time.

Якщо ми їдемо автобусом, то зазвичай приїжджаємо вчасно.

Usually означає «зазвичай»: конструкція сама по собі не гарантує результату в кожному можливому випадку.

**Правило в конкретному місці або системі · emerald**

Умова запускає передбачений порядок дій. Не поширюй локальне правило на всі установи чи пристрої.

If visitors want a badge, they sign in here.

Якщо відвідувачам потрібен бейдж, вони реєструються тут.

**Інструкція: наказова форма, а не Present Simple результату · amber**

Коли кажемо, що слід зробити, після умови вживаємо базову форму дієслова без підмета: це imperative. Для заборони — don't + базова форма. Така умовна інструкція близька за змістом до правила, але не повторює форму present + present.

If you need help, call reception.

Якщо потрібна допомога, зателефонуй на рецепцію.

If the alarm rings, don't use the lift.

Якщо спрацьовує сигналізація, не користуйся ліфтом.

### 3. Справжні помилки форми · mistakes-grid

**Не позначай третю особу двічі.**

Задум помилкового речення: If the scanner doesn't detects a page, it stops.

Якщо сканер не виявляє сторінку, він зупиняється.

Виправлено: If the scanner doesn't detect a page, it stops.

Якщо сканер не виявляє сторінку, він зупиняється.

Переклад виправленого речення: «Якщо сканер не виявляє сторінку, він зупиняється». Розбір: закінчення вже враховане в does, тому потрібна базова форма detect. У помилковому варіанті задуманий зміст той самий.

**З the machine потрібна форма starts.**

Задум помилкового речення: If you press this button, the machine start.

Якщо натиснути цю кнопку, машина запускається.

Виправлено: If you press this button, the machine starts.

Якщо натиснути цю кнопку, машина запускається.

Переклад виправленого речення: «Якщо натиснути цю кнопку, машина запускається». Розбір: the machine — третя особа однини, тому додаємо -s. У помилковому варіанті задуманий зміст той самий.

### 4. Короткий підсумок · summary-list

- Спочатку з’ясуй, чи описуєш типовий зв’язок умови й результату, а не один майбутній випадок.
- Базова модель Zero Conditional — if + Present Simple, Present Simple; заперечення й питання будуються за звичайними правилами Present Simple.
- Інструкція після умови має наказову форму. Не називай її ствердним Present Simple без підмета.
- Порядок частин впливає на звичайне місце коми; вибір if/when залежить від змісту.
- Для можливого майбутнього наслідку порівняй із First Conditional. Правильна інша модель — не граматична помилка.

### 5. Порядок частин, кома та if / when · usage-panels

**Умова на початку — зазвичай із комою · blue**

Можна почати з умови або з результату, не змінюючи їхній зв’язок. Після початкової if-частини зазвичай ставимо кому; перед if-частиною в кінці звичайного речення кома не потрібна.

If you press this button, the machine starts.

Якщо натиснути цю кнопку, машина запускається.

The machine starts if you press this button.

Машина запускається, якщо натиснути цю кнопку.

**If і when: іноді близькі, але не завжди взаємозамінні · sky**

Для повторюваних ситуацій обидва слова можуть передавати зв’язок «щоразу, коли». If підкреслює умову; when — момент її настання. Для разової непевної події if означає «якщо», тоді як when подає її настання як очікуване.

If I work late, I take a taxi home.

Якщо я працюю допізна, то їду додому на таксі.

When I work late, I take a taxi home.

Коли я працюю допізна, то їду додому на таксі.

Не замінюй if на when механічно лише через Present Simple.

### 6. Zero чи First: спочатку зміст · comparison-table

If I work late, I take a taxi home.

Якщо я працюю допізна, то їду додому на таксі.

Повторювана звичка: Zero Conditional.

If I work late tonight, I'll take a taxi home.

Якщо сьогодні я працюватиму допізна, то поїду додому на таксі.

Рішення щодо одного можливого вечора: First Conditional. Обидві моделі граматично правильні.

Застереження: Не оцінюй речення лише за tomorrow. Теперішня форма може повідомляти вже встановлене правило чи рішення; will — прогноз або майбутній наслідок.

### 7. Майбутня дата не скасовує контекст правила · usage-panels

**Чинне рішення чи прогноз на один випадок? · amber**

Організатори заздалегідь постановили: дощ означає скасування завтрашнього матчу. Теперішня форма може оголосити цю умову рішення. Це не нейтральний приклад загальної звички, але й не помилка лише через tomorrow.

If it rains tomorrow, the match is cancelled.

Якщо завтра буде дощ, матч скасовується.

If it rains tomorrow, the match will be cancelled.

Якщо завтра буде дощ, матч буде скасовано.

Другий варіант подає скасування як майбутній наслідок. Обирай пояснення за ситуацією, а не за одним часовим словом.

### 8. Практика Zero Conditional · practice-set

**Завдання 1**

Пристрій працює за сталою схемою: натискання кнопки запускає машину.
If you press this button, the machine ____.



Варіанти: starts / start / does starts.

Ключ: starts. Допустимі: starts.

Пояснення після перевірки:

- starts: Правильно. Речення: If you press this button, the machine starts. Переклад: «Якщо натиснути цю кнопку, машина запускається». Розбір: the machine відповідає it, тому потрібне starts.
- start: Неправильно. Речення: If you press this button, the machine starts. Переклад: «Якщо натиснути цю кнопку, машина запускається». Розбір: у ствердженні з the machine потрібне закінчення -s.
- does starts: Неправильно. Речення: If you press this button, the machine starts. Переклад: «Якщо натиснути цю кнопку, машина запускається». Розбір: звичайне ствердження тут має starts; після допоміжного does форма starts також неможлива.

**Завдання 2**

У цій моделі датчик не працює з розрядженою батареєю. Обери заперечення.
If the battery is empty, the sensor ____.



Варіанти: don't work / doesn't work / doesn't works.

Ключ: doesn't work. Допустимі: doesn't work; does not work.

Пояснення після перевірки:

- doesn't work: Правильно. Речення: If the battery is empty, the sensor doesn't work. Переклад: «Якщо батарея розряджена, датчик не працює». Розбір: the sensor — однина; після doesn't потрібна базова форма work.
- does not work: Правильно. Речення: If the battery is empty, the sensor does not work. Переклад: «Якщо батарея розряджена, датчик не працює». Розбір: повна й скорочена форми заперечення рівнозначні.
- don't work: Неправильно. Речення: If the battery is empty, the sensor doesn't work. Переклад: «Якщо батарея розряджена, датчик не працює». Розбір: з the sensor потрібне does, а не do.
- doesn't works: Неправильно. Речення: If the battery is empty, the sensor doesn't work. Переклад: «Якщо батарея розряджена, датчик не працює». Розбір: після doesn't не додаємо -s.

Сканер щоразу зупиняється, якщо не виявляє сторінку. Виправ форму detects після doesn't, обравши заміну для пропуску.
If the scanner doesn't ____, it stops.
Об’єкт дії — сторінка: a page.



Варіанти: detect a page / detects a page / to detect a page.

Ключ: detect a page. Допустимі: detect a page.

Пояснення після перевірки:

- detect a page: Правильно. Речення: If the scanner doesn't detect a page, it stops. Переклад: «Якщо сканер не виявляє сторінку, він зупиняється». Розбір: після doesn't потрібна базова форма detect без -s та без to.
- detects a page: Неправильно. Речення: If the scanner doesn't detect a page, it stops. Переклад: «Якщо сканер не виявляє сторінку, він зупиняється». Розбір: закінчення третьої особи вже виражене в does, тому detects тут неможливе.
- to detect a page: Неправильно. Речення: If the scanner doesn't detect a page, it stops. Переклад: «Якщо сканер не виявляє сторінку, він зупиняється». Розбір: після допоміжного doesn't не ставимо to.

**Завдання 4**

Що Лена повідомляє цим реченням?

A) Це повторювана реакція на втому.
B) Це обіцянка щодо одного конкретного майбутнього випадку.

Варіанти: a / b.

Ключ: a. Допустимі: a.

Пояснення після перевірки:

- b: Неправильно. Переклад: «Якщо Лена відчуває втому, вона робить коротку перерву». Розбір: тут описано звичку, не одноразову обіцянку. Правильне пояснення — A.

**Завдання 5**

Організатори вже ухвалили правило для завтрашнього матчу: за дощу його скасовують.

A) Речення обов’язково неправильне через слово tomorrow.
B) Речення може оголошувати вже встановлене умовне рішення.

Варіанти: a / b.

B) What you do if the printer stops?

Варіанти: a / b.

## First Conditional

First Conditional пов’язує можливу майбутню умову з прогнозом, рішенням або вказівкою. Базова модель — if + Present Simple, will + початкова форма дієслова.

### m46-first-hero · hero

First Conditional потрібен, коли ми розглядаємо майбутню умову як можливу й кажемо, що зробимо або чого очікуємо за цієї умови. Речення не підтверджує, що умова вже виконалася, і не вимірює ймовірність у відсотках.

**МОЖЛИВА УМОВА**

Після if у базовій моделі стоїть Present Simple, хоча йдеться про майбутнє.

If it rains, we'll stay at home. — Якщо піде дощ, ми залишимося вдома.

**УМОВНИЙ РЕЗУЛЬТАТ**

Will + початкова форма передає прогноз, рішення чи обіцянку, пов’язані з умовою.

If the shop is closed, we'll come back tomorrow. — Якщо магазин буде зачинений, ми повернемося завтра.

**НЕ ГАРАНТІЯ ПОДІЇ**

Мовець пов’язує результат з умовою, але не стверджує, що сама умова обов’язково здійсниться.

If she calls, I'll answer. — Якщо вона зателефонує, я відповім.

### 1. Форма: ствердження, заперечення й запитання · forms-grid

У звичайній майбутній умові обираємо Present Simple; у результаті — will + початкова форма. Після he / she / it у стверджувальній умові не забувай -s. Will однакове для всіх підметів.

**ОСНОВНА МОДЕЛЬ — if + Present Simple, підмет + will + V**

Не додавай will лише тому, що умова стосується майбутнього. Will зі значенням готовності — окремий випадок, а не ця базова модель.

ПРИКЛАД

If we leave now, we will catch the train.
Якщо ми вийдемо зараз, то встигнемо на потяг.

**ЗАПЕРЕЧНА УМОВА — if + підмет + don't / doesn't + V**

Після doesn't дієслово вже без -s. Для be потрібні am not / isn't / aren't.

ПРИКЛАД

If the lift doesn't work tomorrow, we'll use the stairs.
Якщо завтра ліфт не працюватиме, ми скористаємося сходами.

**ЗАПЕРЕЧНИЙ РЕЗУЛЬТАТ — підмет + will not / won't + V**

Для заперечення з won't не потрібні допоміжні do/does; після нього ставимо базову форму без to.

ПРИКЛАД

If the road is icy tonight, we won't drive.
Якщо сьогодні ввечері дорога буде вкрита льодом, ми не поїдемо автомобілем.

**ПРЯМЕ ЗАПИТАННЯ — Will + підмет + V + if + умова?**

У стандартному прямому запитанні will ставимо перед підметом головної частини. Усередині if-частини зберігаємо звичайний порядок слів.

ПРИКЛАД

Will you join us if the café is open?
Ти приєднаєшся до нас, якщо кафе буде відчинене?

КОРОТКА ВІДПОВІДЬ

Yes, I will. / No, I won't.
Так, приєднаюся. / Ні, не приєднаюся.

**ПИТАЛЬНЕ СЛОВО — What / Where / How + will + підмет + V?**

Питальне слово ставимо перед will. Умова з if пояснює, за якої ситуації виникає запитання.

ПРИКЛАД

What will we do if the station is closed?
Що ми робитимемо, якщо вокзал буде зачинений?

**ПОРЯДОК ЧАСТИН І КОМА — if + умова, результат / результат + if + умова**

Можна почати з будь-якої частини. Коли if-частина перша, зазвичай ставимо після неї кому; коли вона друга, у звичайному реченні кома не потрібна.

УМОВА ПЕРША

If I arrive late, I will call you.
Якщо я запізнюся, я тобі зателефоную.

РЕЗУЛЬТАТ ПЕРШИЙ

I will call you if I arrive late.
Я тобі зателефоную, якщо запізнюся.

### 2. Коли вживаємо First Conditional · usage-panels

**ПЛАН АБО ПРОГНОЗ ЗА УМОВИ · emerald**

Майбутнє ще не настало. Ми розглядаємо конкретну можливість і пов’язуємо з нею подальшу дію. If залишає умову відкритою: речення не означає, що подія вже сталася.

If the weather improves, we'll go for a walk.

Якщо погода покращиться, ми підемо гуляти.

If you don't hurry, you'll miss the bus.

Якщо ти не поквапишся, пропустиш автобус.

Will передає позицію мовця — його прогноз або рішення. Самої граматичної форми недостатньо, щоб обіцяти об’єктивно гарантований результат.

**ОБІЦЯНКА АБО ПОПЕРЕДЖЕННЯ · blue**

У результаті можна пообіцяти власну дію або попередити про очікуваний наслідок. Заперечення ставимо саме в ту частину, зміст якої заперечуємо.

If you help me now, I'll help you later.

Якщо ти зараз мені допоможеш, я допоможу тобі пізніше.

If they arrive early, we'll make coffee.

Якщо вони приїдуть рано, ми зваримо каву.

**РЕЗУЛЬТАТ НЕ ЛИШЕ З WILL · amber**

Після умови можливі may / might для непевного результату, can для дозволу чи можливості або наказовий спосіб для вказівки. Це різні значення, а не взаємозамінні слова. У звичайній майбутній if-частині зберігаємо Present Simple.

If the wind drops this evening, we might take the boat out.

Якщо сьогодні ввечері вітер вщухне, ми, можливо, вирушимо на човні.

If you finish this section, you can take a break.

Якщо закінчиш цей розділ, можеш зробити перерву.

If Anna calls, tell her I'm in a meeting.

Якщо Анна подзвонить, скажи їй, що я на зустрічі.

Might не обіцяє результат; can у цьому прикладі дає дозвіл; tell — вказівка співрозмовнику.

**ПРАВИЛО СИСТЕМИ ЧИ КОНКРЕТНИЙ ПРОГНОЗ? · slate**

Обирай модель за змістом, а не лише за словом tomorrow. Present Simple у результаті може описувати те, як працює система; will може подавати відкриття файла як прогноз для конкретної майбутньої дії.

If you press this key tomorrow, the file opens.

Якщо ти натиснеш цю клавішу завтра, файл відкривається.

If you press this key tomorrow, the file will open.

Якщо ти натиснеш цю клавішу завтра, файл відкриється.

Перше речення може описувати чинний механізм, який працюватиме й завтра, тому його не можна оголосити граматично неправильним без контексту. Друге виразно подає майбутній результат. У вправі потрібний вибір має задавати сама ситуація.

### 3. Типові помилки у формі · mistakes-grid

**Не перенось will у if-частину через майбутній час.**

Задум помилкового речення: If it will rain tonight, we'll move the chairs inside.

Якщо сьогодні ввечері піде дощ, ми перенесемо стільці всередину.

Виправлено: If it rains tonight, we'll move the chairs inside.

Якщо сьогодні ввечері піде дощ, ми перенесемо стільці всередину.

Тут rain називає звичайну погодну умову, а не чиюсь готовність. Майбутнє значення не вимагає will після if. Український переклад передає задум обох речень; зайве англійське will у перекладі окремо не відтворюється.

**Не додавай -s двічі.**

Задум помилкового речення: If Iryna doesn't arrives by seven, we'll call her.

Якщо Ірина не прибуде до сьомої, ми їй зателефонуємо.

Виправлено: If Iryna doesn't arrive by seven, we'll call her.

Якщо Ірина не прибуде до сьомої, ми їй зателефонуємо.

Після doesn't потрібна початкова форма arrive, без -s. Переклади однакові за змістом; помилка стосується англійської форми дієслова.

**Після will не ставимо to.**

Задум помилкового речення: If she arrives early, we will to start on time.

Якщо вона прибуде рано, ми почнемо вчасно.

Виправлено: If she arrives early, we will start on time.

Якщо вона прибуде рано, ми почнемо вчасно.

Will уже є модальним дієсловом; далі ставимо start, не to start. Український переклад передає задум помилкового речення, а не узаконює його англійську форму.

### 4. Короткий підсумок · summary-list

- First Conditional пов’язує можливу майбутню умову з результатом; він не підтверджує, що умова вже виконалася.
- Базова модель: if + Present Simple, підмет + will + початкова форма. З he / she / it перевір -s у ствердженні й відсутність -s після doesn't.
- Заперечення: don't / doesn't у звичайній умові; will not / won't у результаті. Запитання: will перед підметом головної частини.
- If-частина може бути першою або другою. Кому зазвичай ставимо після початкової if-частини.
- May / might, can та наказовий спосіб змінюють значення результату. Загальне правило системи й конкретний прогноз не розрізняють лише за tomorrow.

Задум помилкового речення: Якщо під час концерту піде дощ, ми зачинимо вікна. Правильно: If it rains during the concert, we'll close the windows. Правильно: If the bus doesn't arrive by eight, we'll walk to the station. Переклад: Якщо автобус не прибуде до восьмої, ми підемо до вокзалу пішки. Пояснення: тут описуємо майбутню умову, не відмову чи готовність; потрібне doesn't arrive.

Правильно: If the bus doesn't arrive by eight, we'll walk to the station. Переклад: Якщо автобус не прибуде до восьмої, ми підемо до вокзалу пішки. Пояснення: після doesn't дієслово arrive без -s.

- does not arrive: Правильно. If the bus does not arrive by eight, we'll walk to the station. Переклад: Якщо автобус не прибуде до восьмої, ми підемо до вокзалу пішки. Пояснення: does not arrive — повна форма doesn't arrive.

### Докладніше: Коли will після if означає готовність

Власник: m46-first-forms/items/0.

Порівняй два різні запитання до змісту умови: чи подія станеться і чи людина погодиться щось зробити. У другому випадку will може означати готовність; це не допоміжна позначка майбутнього часу. Тому правило базової моделі не слід перетворювати на заборону будь-якого will після if.

If you will carry the small box, I'll carry the large one.

Якщо ти погодишся нести малу коробку, я нестиму велику.

If Danylo comes before noon, we'll have lunch together.

Якщо Данило прийде до полудня, ми пообідаємо разом.

У першому прикладі домовляються про готовність допомогти. У другому важливо, чи відбудеться прихід до полудня; звичайне comes уже може стосуватися майбутнього. Не перенось will із прикладу про згоду до кожної умови про погоду, розклад або прибуття.

## Second Conditional

Second Conditional: уявні ситуації тепер і в майбутньому, форма з would, could і might, заперечення, питання та вправи з поясненнями.

### hero · hero

Second Conditional допомагає уявити іншу ситуацію зараз або в майбутньому та її результат. Минула форма дієслова тут віддаляє сценарій від дійсності, а не переносить його в минуле.

**УЯВНИЙ СЦЕНАРІЙ**

Почни з того, що було б інакше.

If I had more free time, I would learn Italian. — Якби в мене було більше вільного часу, я б вивчав італійську.

**РЕЗУЛЬТАТ ЗА УМОВИ**

Наслідок залежить від уявної умови; це не обіцянка.

If we lived by the sea, we would swim every day. — Якби ми жили біля моря, ми б плавали щодня.

**ПОГЛЯД З ІНШОЇ ПОЗИЦІЇ**

Порада також може бути уявним сценарієм.

If I were you, I would wait. — На твоєму місці я б почекав.

### 1. Форма Second Conditional · forms-grid

Умова: if + підмет + Past Simple. Результат: підмет + would + базова форма дієслова без to. Після would дієслово не отримує -s.

**СТВЕРДЖЕННЯ — if + Past Simple, would + V**

If I knew the answer, I would tell you.
Переклад: Якби я знав відповідь, я б тобі сказав.

**ЗАПЕРЕЧНА УМОВА — if + did not / didn’t + V**

If I didn’t need the car, I would lend it to you.
Переклад: Якби машина не була мені потрібна, я б позичив її тобі.

**ЗАПЕРЕЧНИЙ РЕЗУЛЬТАТ — would not / wouldn’t + V**

If we had a map, we wouldn’t get lost.
Переклад: Якби в нас була карта, ми б не заблукали.

**ПИТАННЯ ПРО РЕЗУЛЬТАТ — Would + підмет + V … if + Past Simple?**

Would you travel more if you had enough money?
Переклад: Ти б більше подорожував, якби мав достатньо грошей?

### 2. Коли вживаємо Second Conditional · usage-panels

**Уявне теперішнє · emerald**

Порівнюємо реальність з уявною альтернативою. У цих ситуаціях машина відсутня або подруга живе далеко. Минула форма називає умову для іншого теперішнього.

If I had a car, I would drive to work.

Якби в мене була машина, я б їздив на роботу автомобілем.

If she lived closer, we would see her more often.

Якби вона жила ближче, ми бачилися б із нею частіше.

If I knew her number, I would call her now.

Якби я знав її номер, я б зателефонував їй зараз.

Останній приклад стосується теперішнього: зараз я не знаю номера. Форма knew сама по собі не означає «знав учора».

**Уявне або малоймовірне майбутнє · blue**

Мовець відсторонено розглядає майбутній сценарій. Подія може бути можливою: Second Conditional не означає, що вона фізично неможлива, і не задає відсотка ймовірності.

If he won the lottery, he would buy a house in Spain.

Якби він виграв у лотерею, то купив би будинок в Іспанії.

If they moved abroad, they would need better English.

Якби вони переїхали за кордон, їм потрібна була б краща англійська.

**Порада через уявну позицію · amber**

Уявляємо себе на місці співрозмовника. Стандартна навчальна формула для такої поради — If I were you.

If I were you, I would talk to her directly.

На твоєму місці я б поговорив із нею напряму.

If I were in your position, I would wait one more day.

На твоєму місці я б почекав ще один день.

### 3. Типові помилки форми · mistakes-grid

**Не підмінюй Past Simple формою would have.**

Задум помилкового речення: If I would have more time, I would read more.

Якби в мене було більше часу, я б більше читав.

Виправлено: If I had more time, I would read more.

Якби в мене було більше часу, я б більше читав.

Задуманий зміст обох варіантів: «Якби в мене було більше часу, я б більше читав». Для звичайної уявної умови про наявність часу потрібне had; would називає результат. Це правило конкретної моделі, не заборона будь-якого if + would: у ввічливих проханнях ця послідовність може мати іншу функцію.

**Після didn’t потрібна базова форма.**

Задум помилкового речення: If she didn’t lived so far away, we would visit her.

Якби вона не жила так далеко, ми б її відвідували.

Виправлено: If she didn’t live so far away, we would visit her.

Якби вона не жила так далеко, ми б її відвідували.

Задуманий зміст обох варіантів: «Якби вона не жила так далеко, ми б її відвідували». Минула форма вже виражена в did; live не отримує -d.

**Не додавай to після would.**

Задум помилкового речення: If I had a bicycle, I would to ride to work.

Якби в мене був велосипед, я б їздив ним на роботу.

Виправлено: If I had a bicycle, I would ride to work.

Якби в мене був велосипед, я б їздив ним на роботу.

Задуманий зміст обох варіантів: «Якби в мене був велосипед, я б їздив ним на роботу». Потрібне would ride, без to. Помилка тут у формі результату, а не в реалістичності ситуації.

### 4. Короткий підсумок · summary-list

- Спочатку визнач зміст: уявне теперішнє або майбутнє, а не повідомлення про минулу подію.
- Умова: if + Past Simple. Результат: would + базова форма; could підкреслює можливість або спроможність, might — можливий результат без упевненості.
- У пораді If I were you обирай were. Не оголошуй кожне розмовне if + was помилкою без контексту.
- Після didn’t та would / wouldn’t став базову форму. У питанні would стоїть перед підметом головної частини.
- Якщо if-частина перша, відділяй її комою. Якщо результат перший, кома зазвичай не потрібна.

### 5. Заперечення, питання й порядок частин · usage-panels

**Заперечуй потрібну частину · blue**

Умова й результат можуть бути заперечними незалежно один від одного. Для звичайного дієслова в умові використовуй didn’t + V; із be — weren’t. У результаті — wouldn’t + V.

If she didn’t work on Saturdays, she would join our walks.

Якби вона не працювала по суботах, вона б приєднувалася до наших прогулянок.

If tickets were cheaper, we wouldn’t stay at home.

Якби квитки були дешевшими, ми б не залишалися вдома.

If the room weren’t so small, we could put a desk by the window.

Якби кімната не була такою маленькою, ми могли б поставити письмовий стіл біля вікна.

**Питай про уявний результат · sky**

У головній частині постав would перед підметом. Питальне слово, якщо воно потрібне, стоїть перед would. В if-частині зберігається звичайний порядок: підмет → дієслово.

What would you change if you ran this café?

Що б ти змінив, якби керував цим кафе?

Would you move abroad if you had the chance?

Ти б переїхав за кордон, якби мав таку можливість?

Yes, I would.

Так, переїхав би.

Коротка відповідь повторює would; вона не потребує повторення всієї умови.

**Порядок частин і кома · slate**

Обидва порядки передають той самий умовний зв’язок. Кома зазвичай потрібна після початкової if-частини, але не перед if, коли спочатку йде результат.

If I had enough money, I would travel more.

Якби в мене було достатньо грошей, я б більше подорожував.

I would travel more if I had enough money.

Я б більше подорожував, якби мав достатньо грошей.

Українська пунктуація перекладу не визначає, чи потрібна кома в англійському реченні.

### 6. If I were you: were і was · usage-panels

**Стандартна модель уявної ситуації · emerald**

В уявних умовах were можна вживати з усіма особами, зокрема I / he / she / it. Це надійний вибір для навчальної моделі та формальнішого письма. У пораді If I were you засвой саме were.

If I were you, I would leave.

На твоєму місці я б пішов.

If this room were larger, we could work here together.

Якби ця кімната була більшою, ми могли б працювати тут разом.

**Розмовний варіант не дорівнює будь-якій помилці · amber**

У неформальному мовленні в уявних умовах із I / he / she / it можна почути was. Воно не робить кожне таке речення автоматично неправильним. Якщо вправа прямо вимагає стандартного were, дотримуйся цієї умови; оцінку регістру не плутай із помилкою форми.

If this room was larger, we could work here together.

Якби ця кімната була більшою, ми могли б працювати тут разом.

Це розмовний варіант попереднього уявного сценарію. Окремо if + was може стосуватися невстановленого факту минулого — тоді значення визначає контекст, а не самі два слова.

### 7. Would, could і might у результаті · comparison-table

Модальне дієслово уточнює результат. Ці форми не завжди взаємозамінні; жодна сама по собі не гарантує, що уявна умова справдиться.

If I had a quiet room, I would record the lesson at home.

Якби в мене була тиха кімната, я б записав урок удома.

Would: результат, який мовець пов’язує з уявною умовою.

If she practised more, she could win.

Якби вона більше тренувалася, вона могла б перемогти.

Could: можливість або спроможність; перемога не подана як гарантована.

If we had a free weekend, we might visit the island.

Якби в нас були вільні вихідні, ми, можливо, відвідали б острів.

Might: один із можливих результатів, без упевненості.

### 8. First чи Second Conditional? · comparison-table

Вибір показує, як мовець розглядає ситуацію. Не обирай тип лише за словом tomorrow і не приписуй конструкції точний відсоток імовірності.

If I get a room near the university, I will walk to class.

Якщо я знайду кімнату біля університету, то ходитиму на заняття пішки.

First: я зараз шукаю житло й розглядаю це як відкриту майбутню можливість.

If I got a room near the university, I would walk to class.

Якби я знайшов кімнату біля університету, то ходив би на заняття пішки.

Second: зараз переїзд не планую; уявляю, що було б за іншої ситуації.

Для форми реальної майбутньої умови дивись First Conditional. Різниця тут у перспективі мовця, а не в тому, що друга подія неодмінно неможлива.

### 9. Практика: Second Conditional · practice-set

**Завдання 1**

У Романа зараз бракує вільного часу. Доповни уявну умову в Second Conditional.
If Roman _____ more free time, he would learn Italian.



Варіанти: had / has / would have.

Ключ: had. Допустимі: had.

Пояснення після перевірки:

- had: Правильно. If Roman had more free time, he would learn Italian. Переклад: Якби в Романа було більше вільного часу, він би вивчав італійську. Had утворює уявну умову про теперішнє; результат уже містить would.
- has: Для названої моделі потрібне had. If Roman had more free time, he would learn Italian. Переклад: Якби в Романа було більше вільного часу, він би вивчав італійську. Тут перевіряємо Second Conditional, не відкриту майбутню умову.
- would have: У звичайній уявній умові про наявність часу потрібне had, не would have. If Roman had more free time, he would learn Italian. Переклад: Якби в Романа було більше вільного часу, він би вивчав італійську. Would стоїть у результаті.

**Завдання 2**

Ми живемо далеко й їздимо автобусом. Уяви інше теперішнє; обери заперечний результат у Second Conditional.
If we lived closer, we _____ the bus.



Варіанти: wouldn’t take / won’t take / don’t take.

Ключ: wouldn’t take. Допустимі: wouldn’t take; wouldn't take; would not take.

Пояснення після перевірки:

- wouldn’t take: Правильно. If we lived closer, we wouldn’t take the bus. Переклад: Якби ми жили ближче, ми б не їздили автобусом. Заперечний результат — would not / wouldn’t + take.
- wouldn't take: Правильно. If we lived closer, we wouldn’t take the bus. Переклад: Якби ми жили ближче, ми б не їздили автобусом. Заперечний результат — would not / wouldn’t + take.
- would not take: Правильно. If we lived closer, we would not take the bus. Переклад: Якби ми жили ближче, ми б не їздили автобусом. Повна й скорочена форми мають однакове значення.
- won’t take: Потрібен уявний результат із wouldn’t. If we lived closer, we wouldn’t take the bus. Переклад: Якби ми жили ближче, ми б не їздили автобусом. Won’t — скорочення will not, а не would not.
- don’t take: Потрібен уявний результат із wouldn’t, не звичайне твердження про теперішнє. If we lived closer, we wouldn’t take the bus. Переклад: Якби ми жили ближче, ми б не їздили автобусом.

**Завдання 3**

Перевір базову форму після would. Обери граматичне завершення, не змінюючи моделі Second Conditional.
If I had a bicycle, I would _____ to work.



Варіанти: ride / to ride / rode.

Ключ: ride. Допустимі: ride.

Пояснення після перевірки:

- ride: Правильно. If I had a bicycle, I would ride to work. Переклад: Якби в мене був велосипед, я б їздив ним на роботу. Після would потрібна базова форма ride без to.
- to ride: Зайве to. If I had a bicycle, I would ride to work. Переклад: Якби в мене був велосипед, я б їздив ним на роботу. Would сполучається з базовою формою без to.
- rode: Rode — минула форма, але після would потрібне ride. If I had a bicycle, I would ride to work. Переклад: Якби в мене був велосипед, я б їздив ним на роботу.

**Завдання 4**

Леся зараз мешкає у квартирі без балкона. Як вона подає ситуацію?
If I had a balcony, I would grow herbs.

A) Вона уявляє інше теперішнє та його результат.
B) Вона розповідає, що вирощувала зелень на своєму балконі в минулому.

Варіанти: a / b.

Ключ: a. Допустимі: a.

Пояснення після перевірки:

- a: Правильно: A. If I had a balcony, I would grow herbs. Переклад: Якби в мене був балкон, я б вирощувала зелень. Умова описує уявну зміну теперішнього; had тут не повідомляє про минуле.
- b: Правильний варіант — A. If I had a balcony, I would grow herbs. Переклад: Якби в мене був балкон, я б вирощувала зелень. Леся уявляє альтернативу теперішньому, а не згадує колишній балкон.

**Завдання 5**

Ти не керуєш кафе, але уявляєш себе його керівником. Який варіант правильно питає про можливі зміни?

A) What you would change if you ran this café?
B) What would you change if you ran this café?

Варіанти: a / b.

Ключ: b. Допустимі: b.

Пояснення після перевірки:

- a: Правильний варіант — B: What would you change if you ran this café? Переклад задуму обох варіантів: Що б ти змінив, якби керував цим кафе? У прямому питанні would має стояти перед you; if you ran зберігає звичайний порядок.
- b: Правильно: B. What would you change if you ran this café? Переклад задуму обох варіантів: Що б ти змінив, якби керував цим кафе? Питальний порядок потрібен у головній частині, але не в if-частині.

**Завдання 6**

Зараз Марта не планує переїзд і лише уявляє життя ближче до університету. Який варіант подає саме цю відсторонену ситуацію, а не відкритий майбутній план?

A) If I get a room near the university, I will walk to class.
B) If I got a room near the university, I would walk to class.

Варіанти: a / b.

Ключ: b. Допустимі: b.

Пояснення після перевірки:

- a: Для заданого погляду потрібне B. A: If I get a room near the university, I will walk to class. Переклад: Якщо я знайду кімнату біля університету, то ходитиму на заняття пішки. B: If I got a room near the university, I would walk to class. Переклад: Якби я знайшла кімнату біля університету, то ходила б на заняття пішки. A граматичне, але подає відкриту можливість; B відповідає відстороненій уяві Марти.
- b: Правильно: B. B: If I got a room near the university, I would walk to class. Переклад: Якби я знайшла кімнату біля університету, то ходила б на заняття пішки. A: If I get a room near the university, I will walk to class. Переклад: Якщо я знайду кімнату біля університету, то ходитиму на заняття пішки. Обидва речення граматичні; контекст Марти визначає потрібну перспективу.
