## Оновлення локального preview

Наявний `M41_LESSONS_PREVIEW_v2.html` зберегти як попередній артефакт. Оновити його дані з нового master, зберігаючи вже виконані технічні виправлення renderer/UI; записати новий файл `M41_LESSONS_PREVIEW_v2_r1.html`.

Прибрати з учнівського інтерфейсу тільки службову редакторську примітку про «форма написалася двічі», оскільки її причину виправлено. Історична згадка в журналі змін допустима. Не прибирати навчальні застереження про часові форми.

Перевірити актуальний preview проти v1.0.1: новий абзац у своєму пункті, незмінний приклад і переклад, незмінні 3 уроки / 18 завдань / 32 controls / 14 details (4/5/5). Точні learner-facing відмінності від початкового авторського v1 обмежені вказаним абзацом; HTML v2 покращує представлення, але не стає окремим авторським джерелом. Будь-які інші відмінності в тексті — STOP до пояснення.

Повторити відповідні desktop/mobile і no-JS перевірки після оновлення. Раніше отриманий PASS стосувався старої версії, а не нового файлу. Прев’ю на диску D: тут не відкривалося й незалежний browser PASS для нього не заявляється.

Після успішної звірки продовжити локальне впровадження без повторного запиту погодження цієї самої редакції.
