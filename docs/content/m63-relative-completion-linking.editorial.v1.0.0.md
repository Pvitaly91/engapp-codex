## Практика і finite відповіді

Рівно18 нових власних завдань: на кожній сторінці2select +2meaning/punctuation choice +2input із ручним і токенним шляхом. Окремо від них —15 реальних type4 питань у трьох5-question widgets. Повні EN/UK речення та52 унікальні plain-text feedback explanations наведені в readable master; HTML і HTML entities для x-text не використовуються.

Шість канонічних inputs мають вісім finite accepted values. Два додаткові варіанти: did not/didn’t для намету та to/in order to для мети Данила. Це обґрунтовані ручні альтернативи, не Cartesian alias matrix. Для п’яти граматичних повних relative-форм у двох Omitting inputs є10 period/no-period rejected feedback keys: повна форма правильна граматично, але не виконує явну zero-relative умову.

У шести meaning choices точний переклад стимулу відкривається після Check, щоб не підказати відповідь; український контекст і критерій видимі. У inputs названі учасники, ролі, лексика й межі альтернатив; перемішаний банк не показує правильного порядку. Нові власні завдання не повторюють15 selected widget answers і не створені просто заміною імен у M62/M27.
