## First Conditional

- Пов’язати значення умови з часом і формою результату.
- Побудувати ствердження, заперечення та пряме запитання.
- Змінити порядок частин і поставити англійську кому.
- Розрізнити близькі граматично правильні моделі за заданим контекстом.
- Уникнути справжньої помилки форми й перевірити відповідь у вправі.

Компоненти: hero, forms-grid, usage-panels, mistakes-grid, summary-list, navigation-chips, practice-set. 1 meaningful detail; 6 tasks / 6 controls.

- Шість початкових source slots збережено за type/column/level; нова практика додається окремим сьомим блоком, без зміни renderer.
- Hero більше не представляє First Conditional як гарантію результату або фіксований рівень імовірності.
- Коротке правило про відсутність will після if обмежено звичайною майбутньою умовою; meaningful sidecar пояснює готовність.
- Формули доповнено запереченнями, стандартним прямим запитанням, короткою відповіддю, питальним словом, порядком частин і комою.
- Старий приклад із press this key tomorrow/file opens перенесено з false-error framing до видимого контекстного порівняння; альтернативний системний зміст збережено.
- Реальну помилку will to start збережено з точним перекладом і поясненням; додано справжню помилку doesn't arrives.
- Власна практика складається лише з supported selected-response controls: 3 selects + 3 choices; немає manual/token fallback або змін answer engine.
- Наявні navigation destinations скопійовано без зміни; їхню локальну доступність має перевірити інтеграційний етап.
- Усі нові EN речення мають UK пару в тому самому basic/detail матеріалі або в per-option feedback; переклади не замінюють граматичного коментаря.

## Спільні рішення

Початкові шість source slots кожного уроку збережені; subtitle має позицію 0, старі блоки — 1–6. Нові компоненти додані після них зі сталими uuid_key. IDs/UUID/anchors чинних блоків не змінюються. Навігація залишається footer-компонентом.

Практика використовує один штатний practice-set на урок: 3 selects + 3 choices, по одному required control на завдання. Всі 45 видимих кандидатів мають окремий перекладений feedback; пояснення не є option label. Manual/token author controls не потрібні для цих шести навчальних цілей. Чинний engine не має перекладеного fallback для довільної хибної manual відповіді; тому цю непідтриману потребу усунуто вибором готових selected-response механік, без нового grader або JS. Наявні linked banks і їхні sentence-builder widgets не редагуються. Випробування duplicate tokens, окремого «?» і ручного редагування для нових author controls не застосовуються; регресії цих механік перевіряються окремо.

Zero/Second: короткі потрібні ремарки залишилися у visible basic, details не вигадувалися. First: окреме пояснення готовності з will має один точний owner /items/0. Повний текст присутній у stored native rules для complete fallback; в погодженій проєкції той самий текст переходить у штатний point-level disclosure.

SEO description у чинній UK в’юсі береться з першого речення hero.intro через PageMetadata::theory; subtitle/Page.text нижчого пріоритету. Title складається зі сталої назви теми. Окремий per-page title override не підтримується, тому нової metadata-інфраструктури немає. Meta/OG/Twitter/structured data перевіряються на live HTML після apply; local noindex зберігається.
