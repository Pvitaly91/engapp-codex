# Оновлення HTML-меню теорії

Перший запуск у новому середовищі: з кореня застосунку з коректним `APP_URL` та доступом до його БД виконайте:

```sh
php artisan theory:menu-build
php artisan theory:menu-build --check
```

Перебудова однієї ввімкненої мови: `php artisan theory:menu-build --locale=uk`. Команда визначає режим сайту за хостом `APP_URL` і бере лише ввімкнені для нього мови. Вона не змінює БД, сесії чи звичайний кеш Laravel. Не потрібно запускати її на кожному розгортанні: повторний build незміненого дерева виводить `unchanged` із тією самою ревізією.

Перебудуйте меню після зміни назви, перекладу назви, порядку, вкладеності, адреси, доступності категорії або уроку, а також після зміни шаблону самого дерева. Зміни звичайних абзаців, завдань, відповідей і прогресу перебудови не потребують.

- Файли: `storage/app/theory-menu/<mode>/<locale>/theory/releases/`; кожен випуск має `desktop.html`, `mobile.html` і `manifest.json`. HTML — runtime-артефакт, його не додають у Git.
- Активна ревізія: `php artisan theory:menu-build --check --locale=uk`. Також її видно в заголовку `X-Theory-Menu-Revision` відповіді `/theory/navigation`. Запис активації з найбільшим порядковим номером лежить в `activations/`; маніфест містить розміри та SHA-256 файлів.
- Якщо команда не завершиться, поточний запис активації не зміниться. Якщо його файли стали недоступні, сайт використовує попередній доступний випуск **того самого контексту** або показує посилання «Усі теми». Дивіться причину у журналі застосунку. HTTP-запит не будує меню.
- Повернення: `php artisan theory:menu-build --rollback --locale=uk`, потім `php artisan theory:menu-build --check --locale=uk`. Команда додає запис про попередню перевірену ревізію, не редагує HTML і не видаляє випуски. Якщо попередньої ревізії немає, команда завершиться помилкою без переключення.

Не видаляйте випуски автоматично: відкриті вкладки можуть ще запитувати відкладене мобільне дерево за старою ревізією. Переконайтеся, що CLI може писати в каталог, а веб-процес має до нього доступ на читання. На новому середовищі до першого успішного build працює доступний резервний блок.
